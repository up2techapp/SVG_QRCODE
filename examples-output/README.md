# Exemples de QR Codes générés

Ce dossier contient des exemples de QR codes SVG générés par le système.

## Fichiers d'exemple

- **QR_E10000.svg** - QR code pour la référence E10000
- **QR_E999999.svg** - QR code pour la référence E999999

## Visualiser les QR codes

Cliquez simplement sur les fichiers `.svg` ci-dessus pour les visualiser directement dans GitHub.

## Générer vos propres QR codes

```bash
# Installer les dépendances
npm install

# Générer un QR code pour une référence
npm run quick E12345
```

Les QR codes que vous générez seront placés dans le dossier `output/` (non versionné).
